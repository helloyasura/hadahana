# System map — Sri Lankan Handahana

## What families ask for

When a Sri Lankan family says they want the **kendara / කේන්දරය** done, they usually want a durable birth record plus counsel for:

1. **Nam Thebima** — first letters of the calling name  
2. Early muhurta — first rice, schooling, travel  
3. Later **porondam galapima** — marriage matching  
4. Timing — Vimshottari maha/antar dasha for life phases  

The chart is a map of tendencies and timing, not a fixed sentence.

## End-to-end workflow of an athurudaya

```
Birth slip (date + exact minute + town/hospital)
        │
        ▼
Civil clock → astronomical time (timezone, optional LMT nuance)
        │
        ▼
Sidereal positions (Lahiri / Chitrapaksha ayanamsa)
        │
        ├── Lagna (horizon + lat/lon)
        ├── Navagraha longitudes
        ├── Chandra → Janma Nekatha + Pada
        └── Whole-sign houses from Lagna
        │
        ▼
Strength / affliction reading (lords, aspects, yogas, shadbala ethos)
        │
        ├── Nam Thebima letters (pada syllables + optional filters)
        ├── Vimshottari timeline from Janma Nekatha lord
        └── Counsel (gentle; tendencies + timing)
        │
        ▼
Optional heirloom: palm-leaf kendara (තල්පත් කොළ)
```

## Three pillars every reading needs

1. **Lagna** — body, path, house frame  
2. **Chandra + Janma Nekatha** — mind, naming, dasha seed, porondam base  
3. **Navagraha in 12 bhava** — which life rooms are activated  

Western “Sun sign” newspaper columns are not this system. SL practice is **sidereal**, **Moon-heavy**, and **dasha-timed**.

## What makes Sri Lankan practice distinct

- Anchored to **island coordinates** and local civil time (`Asia/Colombo`, no DST).  
- Working literature is largely **Sinhala** (Godage, Gunasena handbooks).  
- Everyday culture braids Jyotisha with **Buddhist / folk** timing habits (nekath for openings, travel, naming).  
- Matching tradition: **Dasa Porondam** (10) and often **Visi Porondam** (20); Tamil families may use Pathu Porutham with small rule differences.  
- Older arithmetic used **පංචාංග ලිත්** remainder tables and **Lith Illakkam** numerals on ola leaves; modern athurudayas often keep the *reading craft* and use ephemeris software for *numbers*.

## Inputs that must never be guessed

| Input | Why |
| --- | --- |
| Exact hospital clock time | Lagna ~2h; pada ~6h; sandhi minutes flip letters |
| Birth town / hospital | Ascendant depends on lat/lon |
| Time zone / DST history (abroad) | Wrong UTC → wrong everything |
| Ayanamsa choice | SL software defaults **Lahiri**; KP/Raman shift nekatha borders |

If time is approximate, the report must say so.
