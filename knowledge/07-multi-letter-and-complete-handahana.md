# Multi-letter Nam Thebima + complete Handahana (කේන්දර පලාපල)

## Yes — primary letters are a *set*, not only one sound

Experienced Sinhala practice does **not** stop at a single pada syllable. Athurudayas normally offer a **ranked letter pool**.

### Layer A — Primary (strongest)

- Exact **Janma Nekatha + Pada** syllable (e.g. පුවපල් pada 1 → **මො**).
- This is the first choice for the calling name’s opening sound.

### Layer B — Subha-class nekatha letters (several more)

From the birth star, count the 9-fold Tara cycle (repeats across 27 stars):

| Offset | Class (Sinhala) | For naming |
| --- | --- | --- |
| 0 | ජන්ම (Janma) | Allowed (primary star) |
| 1 | සම්පත් (Sampath) | Favour |
| 2 | විපත් (Vipath) | Avoid |
| 3 | ක්ෂේම (Kshema) | Favour |
| 4 | ප්‍රත්‍යාරි (Pratyari) | Avoid |
| 5 | සාධක (Sadhaka) | Favour |
| 6 | වධ (Vadha) | Avoid |
| 7 | මෛත්‍රී (Maitri / Mitra) | Favour |
| 8 | පරම මෛත්‍රී (Parama Maitri) | Favour |

**Favour classes** → take their pada syllables into the recommended letter set.  
**Avoid classes** → do not recommend those stars’ letters for the name start.

So one birth yields: **1 primary + many secondary subha letters**.

### Layer C — Secondary classical pools

- **Lagna** letter set (from Lagna rashi table)
- **Weekday** letter set (crudest)

Experienced order of preference: **A → B → C**. Intersection of A∩C or A∩Lagna is often presented as “especially good.”

### Layer D — Shabda filters (optional strict mode)

- Prefer divya/manushya starting letters over apaya  
- Avoid akshara-vedha with parents/siblings  
- Name mātrā gana check  
- Easy pronunciation in Sinhala + Latin script

## Complete Handahana / Kendara Palapala sections

A full person detail report (not letters-only) should cover:

1. **Birth record** — date, exact time, place, ayanamsa, JD  
2. **Lagna palapala** — rashi, degree, lagna lord, temperament/body path  
3. **Chandra / Nekatha palapala** — moon sign, janma nekatha, pada, mind nature  
4. **Nam Thebima letter set** — Layers A–C (and D if requested)  
5. **Navagraha sputa** — each graha: rashi, degree, bhava, dignity flags  
6. **Bhava reading** — 12 houses with occupants + lord notes  
7. **Yogas / dosha flags** — e.g. Gajakesari-class, Raja/Dhana hints, Kuja, Kalsarpa (gentle)  
8. **Navamsa (D9)** — at least D9 lagna + marriage-relevant notes  
9. **Vimshottari** — maha balance at birth, antar, forward timeline  
10. **Muhurta notes** — naming/ceremony: Subha Nekatha, avoid Rahu Kalaya  
11. **Disclaimer** — tendencies + timing, not fixed fate; escalate medical/legal to humans  

This is what “prepare complete Handahana based on those details” means in Stage 2 product scope.
