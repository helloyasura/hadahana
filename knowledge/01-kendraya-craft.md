# Kendraya craft — how the chart is made

## Classical job of the chart

A kendraya does three things at once (as described by working SL masters such as Wimal Jayasuriya’s craft notes):

1. Fix planetary positions at first breath.  
2. Map them onto **12 bhava** (life rooms).  
3. Speak karmic *tendencies* and *timing* — not fixed fate.

## Time conversion

Traditional teaching:

1. Take the **recorded clock time** (do not “correct from memory”).  
2. Place it in the birth town’s civil / mean-time frame.  
3. Convert to sidereal reckoning.  
4. Apply **ayanamsa** (precession offset).  

For Sri Lanka today: hospital clocks use **Asia/Colombo = UTC+5:30**, no daylight saving.  
Rural teachers historically also spoke in **Sinhala hora** (60-hour day on Kandyan clocks). Modern hospital charts use standard 24h clock — **do not mix systems**.

## Zodiac and houses

- **Sidereal rashis** (මේෂ … මීන), not tropical Western signs.  
- Common SL software/charts use **whole-sign houses** from Lagna (each bhava = one rashi).  
- North-Indian diamond layout is widely shown online; South-Indian square also appears. Reading order differs visually; mathematics of whole-sign from Lagna is the same idea.

## Navagraha

Sun, Moon, Mars, Mercury, Jupiter, Venus, Saturn, Rahu, Ketu.

Judgement layers used by serious readers (even if software only approximates):

- Dignity: exaltation / own / friend / enemy / debilitation  
- Combustion, retrograde, graha yuddha  
- Aspects (drishti)  
- **Shadbala** ethos (sixfold strength) — traditionally taught even when modern tools shortcut it  
- Special flags families fear/ask about: **Kuja dosha**, **Kalsarpa**, etc. — must be explained carefully, not weaponized

## Chandra layer (older and deeper)

27 **nakshatras** × 13°20′. Moon’s mansion at birth = **Janma Nekatha**.  
Each nekatha has a **lord** that seeds **Vimshottari** dasha.

Vimshottari years (120-year cycle), used in SL Maha Dasa teaching:

| Lord | Years |
| --- | --- |
| Ketu | 7 |
| Venus | 20 |
| Sun | 6 |
| Moon | 10 |
| Mars | 7 |
| Rahu | 18 |
| Jupiter | 16 |
| Saturn | 19 |
| Mercury | 17 |

Order is fixed. Birth balance = remaining portion of the Moon’s nekatha lord’s maha period. Antar (bhukti) subdivides each maha.

## Divisional charts often paired

- **D1** Rashi — main life  
- **D9** Navamsa — marriage / dharma confirmation (always mentioned in serious SL software)  

Others (Hora D2, etc.) appear in fuller software; Stage 1 notes them as optional depth.

## Palm-leaf heirloom practice

- Medium: **තල්පත් කොළ** (talipot), iron stylus, plant/mineral ink  
- Kandyan-era ola use **Lith Illakkam** (astrological numerals)  
- Work often begun only in a chosen muhurta with a settled mind  
- Digital calc + human counsel + optional leaf copy is the modern compromise

## Manual vs software (rural reality)

Lanka Jhothisha Arana notes: most practitioners start mid-calculation from **Lith tables** (lagna remainder, nekatha time). Pure sky + hereditary tables are rare now. Software removed lith-print errors but also thinned training in foundational ganita. An “experienced agent” must therefore:

- Own **correct ephemeris math** (Swiss / Drik)  
- Own **interpretive craft** in Sinhala cultural voice  
- Never pretend lith nostalgia replaces precision
