No sourced Buddhist boy name for **ට/ටි** is approved in this catalogue. These
results honestly use the **other already allowed letters**, including existing
base-consonant allowances; e.g. Puneeth/පුනීත් is a ප-base match, not an exact පි
syllable match. No dental ත is substituted for retroflex ට.

Janeesh, Vidiyan, Mihin, Mithum, Pavith, Pinsara, Ravindu and Kavindu now have
explicit qualified root-derived readings. Janeesh/Vidiyan do not match this
fixture’s letters and must not be forced into it. Mineth, Minula, Pinith, Pamith,
Pulith, Tishan, Monica and Malani remain review-only and are not in this default
list. See [sources and decisions](NAMES.md) and [all-letter gaps](NAMES_COVERAGE.md).
